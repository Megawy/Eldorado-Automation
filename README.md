# Eldorado Automation

An Angular seller dashboard and a browser-extension foundation for Eldorado marketplace automation.

## Project layout

- `src/app` — standalone Angular dashboard, core services, shared UI, and lazy-loaded features.
- `src/extension` — isolated browser-extension background, content, DOM integration, messaging, and storage code.
- `src/models` — contracts shared by the dashboard and extension.
- `docs` — architecture and integration notes.

## Development

```bash
npm install
npm start
npm run build
```
